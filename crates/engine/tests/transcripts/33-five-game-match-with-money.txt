title: A five-game match: each partnership wins one game, then the decider; the losers pay the stake
story: A whole match of five games, each won as fast as possible, by a jink in a single hand. The deal moves one seat left every hand, so the first player (the jinker) is a different partnership each time.
story: Game 1: seat 7 deals and seat 0 makes a jink (team 0). Game 2: seat 0 deals and seat 1 makes a jink (team 1). Game 3: seat 1 deals and seat 2 makes a jink, starting with the 5 of diamonds, whose bonus counts at once (team 2). Game 4: seat 2 deals and seat 3 makes a jink (team 3).
story: After four games every partnership has won one game. Each new game starts from nought (rule 36); the games won are kept.
story: Game 5, the decider: seat 3 deals and seat 4 makes a jink, so team 0 (seats 0 and 4) wins its second game and the match (rule 35).
story: Money (H6, stake 5): every player of the three losing partnerships pays 5 to the winners. Per partnership: team 0 +30, teams 1, 2 and 3 -10 each.
dealer: 7
